9.2 在线训练平台注册
 
在线训练模型地址:https://www.kendryte.com/zh/training/dataset
1. 我们来到勘智官网，这里我们可以注册也可以选择登录（这里我们以注册为例）。
2. 我们点击注册按键，开始注册。


===== PAGE 2/13 =====

3. 填写对应的个人信息，点击注册
9.3 开始在线训练模型
 
1. 注册成功后账号会自动登录，我们点击右边的“创建数据集”。


===== PAGE 3/13 =====

2. 这里我们以图像检测为例子，创建数据集，我们输入对应的数据集名称以及选择对应的识别、标注类型。
3. 点击右上角“配置”按钮。
4. 点击上传图片按钮将对应的数据集上传到云平台中。
5. 将准备好的数据集上传模型训练云平台。


===== PAGE 4/13 =====

6. 图片上传完成后点击标注按钮
7. 点击新标签添加对应类被的标签。
8. 我们添加green 、red 、yello 标签用于红绿灯识别。


===== PAGE 5/13 =====

9. 选中对应的颜色标签（这里我们以绿色为例），拖动鼠标标注出对应的待检测物体。
10. 将全部的图片添加上对应的标注。
11. 全部标注完成后，我们点击返回按钮。


===== PAGE 6/13 =====

12. 接着，点击训练按钮开始模型的训练。
13. 填写对应的训练参数
* 运行芯片：我们这里选择K230。
* nncase版本：选择最新的版本即可。
* 迭代次数：这里可以根据数据集做出调整，一般200左右即可。（当连续 30~50 epoch loss 基本不再下降（变化 < 
0.05）时，系统将停止继续训练）。
* 批数据量大小：选择8即可。
* 最大学习率：填写0.001即可。
* 标注框限制：填写5即可（同一张图里，最多允许多少个目标框）。


===== PAGE 7/13 =====

14. 点击确定后自动跳转到训练界面，等待训练即可（人多的时候训练需要排队）。
15. 由于训练是在云端的训练，我们可以关闭网页或者浏览器都不会影响训练。


===== PAGE 8/13 =====

16. 我们在训练的过程中可以将鼠标移动到训练结果图表中实时观看对应的loss 数据。
17. 在训练结束后注册的邮箱将会收到对应的邮件提示模型训练的结束。
