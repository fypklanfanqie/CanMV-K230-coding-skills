2. 软件工具：提供K230开发板全套软件工具，包含CanMV IDE集成开发环境、镜像烧录工具、串口终端、SD卡格

3. 系统镜像&芯片资料&AI模型文件：包含系统镜像、AI模型文件、引脚定义及芯片资料（如数据手册、参考手册

4. 拓展学习资料：提供openCV相关的一系列学习资料；
5. 程序源码：包含K230视觉图形算法等源代码，开放可修改。
2.教程资料目录（重点）
 
此内容是：“1教程资料”内课程内容目录。

3. 多媒体课程：提供多媒体与交互应用示例，涵盖屏幕显示、音频播放与录制、视频处理及图形用户界面（LVGI）
等实验。
4. OpenMV课程（重点）：提供丰富的机器视觉算法示例，涵盖颜色识别（单色/多色识别、物体计数、视觉巡

等）。
5. AI视觉教程：提供丰富的AI应用示例，涵盖人脸识别与分析（检测、关键点、3D建模、姿态估计、身份识别）、
人体检测与分析（检测、关键点、跌倒检测）、手部识别与手势交互（手掌识别、关键点检测与分类、动态手势
识别及“石头剪刀布”游戏）、车牌与文字识别（检测与识别），以及基于YOLOv8的自学习、物体检测、实例分割
与目标追踪等进阶视觉任务。
6. 网络基础课程：提供全面的网络通信示例，涵盖有线与无线网络连接、TCP/UDP 通信（支持 Client/Server 模
式）及 HTTP 应用（Client 与 Server 实验）。
7. 触摸功能课程：提供触摸交互应用示例，包括触摸检测、触摸画板及触摸拍照功能。
8. 大模型课程：提供完整的AI语音与认知交互示例，涵盖大模型API-KEY获取、语音唤醒、语音识别与合成，以及
文字与图片高级理解功能。
3.学习路线
 
为了帮助你高效地学习和掌握K230开发板，我们建议按照以下循序渐进的路径进行学习：
第一阶段：快速入门与基础准别(建议优先完成)
第一章 快速使用 (必看)：
了解学习K230开发板的基础功能、硬件接口说明、使用教程以及注意事项。
学习工具的安装使用（CanMV IDE、串口工具、网络助手等）、镜像的烧录以及基础环境的配置。


===== PAGE 3/3 =====

第二阶段：基础外设与通信控制
1. 第二章 基础课程：
学习GPIO、PWM、ADC、RTC、WDT、TIMER等基础外设的控制方法。
掌握UART、I2C、SPI等通讯协议的例程。
进阶学习 FFT频谱分析、SHA256/AES加密、多线程编程 、文件读取等 。
2. 第六章 网络基础课程 ：
学习有线/无线网络连接配置。
掌握TCP/UDP/HTTP通信（包含Cilent/Server模式)。
第三阶段：多媒体与交互应用
1. 第三章 多媒体课程：
实时屏幕显示、音频录制与播放、视频处理以及图形用户界面（LVGI）应用。
第四阶段：机器视觉与AI应用（核心进阶）
1. 第四章 OpenMV课程：
学习了解掌握颜色识别（单色/多色、物体计数、视觉巡线）、码类识别（QR码、DM码、AprilTags等）以及图像
检测（线段、矩形、圆形、边缘检测等）。
2. 第五章 AI视觉教程：
学习了解人脸识别（包含人脸检测、关键点、3D建模、姿态估计）、人体检测（关键点、跌倒检测）、手部识别与
手势交互以及车牌与文本识别（OCR）。
进阶学习 YOLO系列的自学习、物体检测、目标追踪与实例分割。
3. 第七章 触摸功能课程：
学习开发板中LCD屏幕中触摸功能学习，实现触摸画图，触摸拍照等玩法。
4. 第八章 AI大模型课程:
学习了解阿里云百炼大模型(包含语音唤醒、语音识别、语音合成、文字理解、图片理解)。
第五阶段：拓展学习与深入开发
程序源码：在完成上述K230核心课程后，结合提供的K230视觉图形算法源代码进行二次开发与修改。
拓展学习资料：学习OpenCV等及计算机视觉库的进阶应用。
芯片资料:查阅数据手册、参考手册、深入了解K230硬件架构与底层驱动。
