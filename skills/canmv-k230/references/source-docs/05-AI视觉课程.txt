===== PAGE 14/160 =====

1. FaceDetApp ：加载人脸检测模型并进行人脸检测
2. kmodel_path ：人脸检测模型的路径。
3. model_input_size ：该模型所要求的输入图像尺寸。
4. anchors ：锚框，目标检测模型通常使用不同尺度的锚框来匹配真实目标。
5. confidence_threshold ：置信度阈值，只有当模型预测的人脸框的置信度超过这个阈值时才会被视为有效人
脸。
6. nms_threshold ：非极大值抑制阈值，用于消除重叠的检测框。它可以去除那些重叠度高于设定阈值的重复
框。
图像预处理
1. 图像预处理的目的是将原始输入图像转换成适合模型的格式。调整图像的尺寸、颜色转换、归一化、数据增强等
操作。
2. letterbox_pad_param ：根据输入图像的尺寸与模型的输入尺寸（计算所需的填充），确保图像按比例缩放并填
充到目标尺寸。
3. self.ai2d.pad ：对图像进行填充处理，填充的颜色为[104,117,123]，进行图像预处理时调整输入大小，并防
止模型因为图像尺寸不一致而出错。
4. self.ai2d.resize ：调整图像尺寸，以适应模型的输入大小。
返回有效框

        left_pad = int(max(0, -context_xmin))
        top_pad = int(max(0, -context_ymin))
        right_pad = int(max(0, int(context_xmax - self.rgb888p_size[0] + 1)))
        bottom_pad = int(max(0, int(context_ymax - self.rgb888p_size[1] + 1)))
        context_xmin += left_pad
        context_xmax += left_pad
        context_ymin += top_pad
        context_ymax += top_pad
        return [top_pad,bottom_pad,left_pad,right_pad,
