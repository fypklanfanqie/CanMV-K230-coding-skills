4.1 单一颜色识别 
 
4.1.1 实验简介
 
本节通过程序学习k230开发板的颜色识别功能，find_blobs  是 OpenMV 的图像处理函数，用于在图像中寻找并识
别“斑点” （blobs）。这些斑点是指图像中具有相似颜色或亮度的区域。

1. img = sensor.snapshot() : 从摄像头捕获一帧实时图像。
2. lines = img.find_lines(...) :在捕获到的 img 图像上执行“霍夫变换（Hough Transform）”，用于在图像中

3. threshold=1000 : 阈值参数。一个像素点集要被认为是“直线”，它在霍夫空间中的累加值必须高于这个阈值。值
越高，检测出的直线越可靠。
4. theta_margin=25, rho_margin=25 : 这两个参数用于合并距离和角度都很相近的线段，防止算法对同一条物理
直线输出多个非常相似的检测结果。
5. img.draw_line(l.line(), color=(255, 0, 0)) : 对于每一条检测到的直线，调用 draw_line  函数，在原
始图像上用红色把它画出来。l.line() 会返回这条线的两个端点坐标。
6. Display.show_image(img) : 将这帧画好了红色标记线的图像，发送到显示设备上。
