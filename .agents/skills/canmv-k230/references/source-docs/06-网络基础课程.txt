socket  用于TCP网络通信，network  用于WiFi连接管理，time  用于延时操作，CONTENT  是服务器每
次向客户端发送的欢迎信息模板，有一个数字占位符。
主程序
将'your_ssid_name'和'your_ssid_password'替换成实际的热点名称和密码。
初始化STA接口模式（站点模式，即连接路由器），如果未连接就尝试连接指定 WIFI_SSID 和 
WIFI_PASSWORD，并每隔500毫秒打印“.”进度表示，直到连接成功，连接成功后打印所获IP及其它网络
配置信息。
socket.socket  创建一个IPv4(TCP) socket ，setsockopt 设置端口可重用，防止“地址已被占用”错
误，使用 getaddrinfo  获取本机IP的socket 地址结构，将socket 绑定到本机IP的8080端口，启动监
听，允许最多5个挂起的连接请求，打印服务器启动完成信息。
#配置 tcp/udp socket调试工具
import socket
import network
import time
CONTENT = b"""
Hello #%d from k230 canmv MicroPython!
"""
    WIFI_SSID = "your_ssid_name"
    WIFI_PASSWORD = "your_ssid_password"
    wlan = network.WLAN(network.STA_IF)
    if not wlan.isconnected():
        print('正在连接到WiFi网络...')
        wlan.connect(WIFI_SSID, WIFI_PASSWORD)
        while not wlan.isconnected():
            print('.')
            time.sleep_ms(500)
    ip = wlan.ifconfig()[0]
    print('网络已连接，IP配置:', wlan.ifconfig())
    counter = 1
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM, 0)
    s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    ai = socket.getaddrinfo(ip, 8080)
    addr = ai[0][-1]
    s.bind(addr)
    s.listen(5)
    print("TCP服务器已启动于 %s 端口:%d\n" % (ip, 8080))


===== PAGE 22/59 =====

counter 初始为1，限制服务器只处理10个客户端连接，accept() 阻塞直到有客户端连接，获取连接的
客户端socket对象和其IP端口信息，打印连接客户端的地址信息，进行 WiFi 连接并等待结果。如果未连
接 WiFi，则调用 connect()  启动连接。进入循环，等待连接成功，超时 15 秒自动退出（防止死等）。
wlan.isconnected() 实时轮询连接状态。
进入内部无限循环，不断读取客户端数据，read() 操作非阻塞，异常11等价于 EAGAIN，表示数据暂时
不可读，忽略继续循环。如果成功读取到非空数据，则打印收到的消息，回复客户端字符串 "recv :<收到
的数据>"。如果数据中包含字节串 "end"，判定客户端想关闭连接，跳出循环，每次循环阻塞100毫秒，
降低CPU占用。
