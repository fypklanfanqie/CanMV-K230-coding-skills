出现ModuleNotFoundError: No module named 'torch' 这意味着：
1. 在你当前运行代码的环境里，压根就没有安装 PyTorch。

支持到 CUDA 11.0，但你装了 12.1）。

10.4 使用YOLOv8训练猫狗分类
 
10.4.1 开始训练
 
1. 进入工作目录：输入下面指令回到YOLOv8目录中
2. 输入下面指令开始训练：
cd E:\dog_and_cat_detection\ultralytics
yolo detect train data=E:\dog_and_cat_detection\pet_data\dataset_formatted\data.yaml 
model=yolov8n.pt epochs=50 imgsz=320 batch=16 device=0 project=runs/train name=pet_k230_v8


===== PAGE 22/29 =====

参数详解：
yolo detect train ：启动 YOLOv8 的训练模式。
data=... ：告诉程序数据集配置文件的位置
model=yolov8n.pt ：使用“Nano”版本的预训练模型
epochs=50 ：让模型把整个数据集学习 50 遍。
imgsz=320 ：把图片缩放成 
 像素进行训练。
batch=16 ：一次塞给显卡 16 张图处理。
device=0 ：使用第一块显卡（GPU）跑训练。
project/name ：结果保存在 runs/train/pet_k230_v8  文件夹下。
10.4.2 模型验证
 
1. 输入下面指令测试训练的模型：
参数详解：
yolo predict ：启动 YOLOv8 的推理（预测）模式。
model=best.pt ：加载你训练出的效果最好的那份模型权重。
source=.../Abyssinian_1.jpg ：指定测试图片的路径。
imgsz=320 ：推理前将图片缩放至 
 像素（必须与导出后的 K230 输入一致）。
conf=0.25 ：置信度阈值。只显示概率大于 25% 的物体（默认值）。
save=True ：告诉程序保存画好框的预测结果图（默认开启）。
2. 前往查看验证图片：E:\dog_and_cat_detection\ultralytics\runs\detect\predict 查看验证图片

from libs.PipeLine import PipeLine, ScopedTiming
from libs.YOLO import YOLOv8
import os, sys, gc
if __name__ == "__main__":
    #模型路径
    kmodel_path = "/sdcard/pet_cat_dog_norm.kmodel"
    #标签列表
    labels = ["cat", "dog"]
    #模型输入尺寸 必须是模型训练时的输入尺寸。
    model_input_size = [320, 320]
    #阈值设置
    confidence_threshold = 0.7
    nms_threshold = 0.7


===== PAGE 29/29 =====

4. 模型加载与预处理
5. 主循环
 
    #屏幕与摄像头配置
    rgb888p_size = [1280, 720]  # 摄像头采集分辨率
    display_size = [800, 480]   # 屏幕显示分辨率
    #这里建立了一个从摄像头（1280x720）到屏幕（800x480）的数据通路。系统会自动处理缩放
    pl = PipeLine(rgb888p_size=rgb888p_size, display_size=display_size, display_mode="lcd")
    pl.create()
    # 初始化 YOLOv8 实例
    yolo = YOLOv8(task_type="detect",               # 告诉类库这是一个“检测”任务。
                  mode="video",                     # 视频模式。通常意味着模型会持续处理连续帧，库
内部可能会优化 Buffer 缓存逻辑。
                  kmodel_path=kmodel_path,          # 模型路径
                  labels=labels,                    # 标签列表
                  rgb888p_size=rgb888p_size,        # 原始输入尺寸
                  model_input_size=model_input_size,    # 模型输入尺寸
                  display_size=display_size,            # 显示尺寸
                  conf_thresh=confidence_threshold,     # 置信度阈值
                  nms_thresh=nms_threshold,             # 非极大值抑制
                  debug_mode=0)                         # 调试模式,输出详细的识别信息0关闭1开启
    yolo.config_preprocess()
    try:
            print("YOLOv8 模型加载成功，开始运行检测...")
            while True:
                os.exitpoint()
                with ScopedTiming("total", 1):
                    img = pl.get_frame()      # 获取图像
                    res = yolo.run(img)       # 推理
                    yolo.draw_result(res, pl.osd_img) # 绘制结果
                    pl.show_image()           # 显示
                    gc.collect()              # 内存回收
        except Exception as e:
            sys.print_exception(e)
        finally:
            yolo.deinit()
            pl.destroy()
            print("程序已停止")
