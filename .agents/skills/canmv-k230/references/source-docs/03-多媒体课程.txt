3.1 Sensor实验说明 
 
3.1.1 实验简介
 
本节通过程序学习利用 K230 的三通道输出能力，把同一摄像头画面同时以三种不同分辨率/格式送到三块显示区域，
实时对比效果。
K230 具备 3 路 MIPI-CSI 输入（3x2 lane/1x4+1x2 lane），最多可连接 3 路摄像头，每路摄像头支持输出 3 个通道，
提供不同的分辨率和图像格式。

import time, os, urandom, sys
from media.display import *
from media.media import *
import image
    try:
        # --- 步骤 3: 主循环，用于绘制和显示 ---
        while True:
            # 清空画布，准备重新绘制
            img.clear()
            # 在画布的随机位置绘制10个彩色的字符串
            for i in range(10):
                x = (urandom.getrandbits(11) % img.width())
                y = (urandom.getrandbits(11) % img.height())
                r = (urandom.getrandbits(8))
                g = (urandom.getrandbits(8))
                b = (urandom.getrandbits(8))
                size = (urandom.getrandbits(30) % 64) + 32


===== PAGE 11/29 =====

1. img.clear() : 在每一帧绘制开始前，将内存画布完全清空。
2. urandom.getrandbits() : 获取高质量的随机数，用来决定字符串的位置(x, y)、颜色(r, g, b)和大小(size)，带来
了不可预测的动态性。
3. img.draw_string_advanced() : 在内存画布 img 上执行实际的绘制操作。
4. Display.show_image(img) : 它将内存画布 img 中已经绘制好的完整图像，一次性地“推送”或“刷新”到物理屏幕
上。这种“先在内存中画好，再一次性显示”的机制，被称为双缓冲，可以防止画面撕裂和闪烁。
5. time.sleep(1) : 让程序暂停1秒。它控制着动画的帧率（此处为1 FPS），使得可以清晰地看清每一帧的画面。

import os
from media.media import *   #导入media模块，用于初始化vb buffer
from media.pyaudio import * #导入pyaudio模块，用于采集和播放音频
import media.wave as wave   #导入wav模块，用于保存和加载wav音频文件
def record_audio(filename, duration):
    CHUNK = 44100//25  #设置音频chunk值
    FORMAT = paInt16       #设置采样精度,支持16bit(paInt16)/24bit(paInt24)/32bit(paInt32)
    CHANNELS = 2           #设置声道数,支持单声道(1)/立体声(2)
    RATE = 44100           #设置采样率
    try:
        p = PyAudio()
        p.initialize(CHUNK)    #初始化PyAudio对象
        MediaManager.init()    #vb buffer初始化
        #创建音频输入流
        stream = p.open(format=FORMAT,
                        channels=CHANNELS,
                        rate=RATE,
                        input=True,
                        frames_per_buffer=CHUNK)
        stream.volume(vol=70, channel=LEFT)
        stream.volume(vol=85, channel=RIGHT)
        print("volume :",stream.volume())
        #启用音频3A功能：自动噪声抑制(ANS)
        stream.enable_audio3a(AUDIO_3A_ENABLE_ANS)
        frames = []
        #采集音频数据并存入列表
        for i in range(0, int(RATE / CHUNK * duration)):
            data = stream.read()
            frames.append(data)
            if exit_check():
                break
        #将列表中的数据保存到wav文件中
        wf = wave.open(filename, 'wb') #创建wav 文件
        wf.set_channels(CHANNELS) #设置wav 声道数
        wf.set_sampwidth(p.get_sample_size(FORMAT))  #设置wav 采样精度
        wf.set_framerate(RATE)  #设置wav 采样率


===== PAGE 16/29 =====

1. for i in range(0, int(RATE / CHUNK * duration)) 这是一个精确控制录音时长的计数循环。它通过音频
的采样率(RATE)、块大小(CHUNK)和总时长(duration)预先计算出需要执行的总次数，以确保录音达到指定的秒
数。
2. data = stream.read() 作用：执行核心的录音操作。音频设备从输入流（即麦克风）的硬件缓冲区中读取一个
数据块（CHUNK）的原始音频数据。
3. frames.append(data) 作用：将刚刚从麦克风捕获到的音频数据块 data  添加到一个名为 frames  的 Python 
列表中。此操作将所有音频数据按顺序暂存在内存里，为录音结束后一次性写入文件做准备。
播放主循环分析
        wf.write_frames(b''.join(frames)) #存储wav音频数据
        wf.close() #关闭wav文件
    except BaseException as e:
            print(f"Exception {e}")
    finally:
        stream.stop_stream() #停止采集音频数据

def play_audio(filename):
    try:
        wf = wave.open(filename, 'rb')#打开wav文件
        CHUNK = int(wf.get_framerate()/25)#设置音频chunk值
        p = PyAudio()
        p.initialize(CHUNK) #初始化PyAudio对象
        MediaManager.init()    #vb buffer初始化
        #创建音频输出流，设置的音频参数均为wave中获取到的参数
        stream = p.open(format=p.get_format_from_width(wf.get_sampwidth()),
                    channels=wf.get_channels(),
                    rate=wf.get_framerate(),
                    output=True,frames_per_buffer=CHUNK)
        #设置音频输出流的音量
        stream.volume(vol=85)
        data = wf.read_frames(CHUNK)#从wav文件中读取数一帧数据
        while data:
            stream.write(data)  #将帧数据写入到音频输出流中
            data = wf.read_frames(CHUNK) #从wav文件中读取数一帧数据
            if exit_check():
                break
    except BaseException as e:
            print(f"Exception {e}")
    finally:
        stream.stop_stream() #停止音频输出流
        stream.close()#关闭音频输出流
        p.terminate()#释放音频对象


===== PAGE 17/29 =====

1. wf = wave.open(filename, 'rb') : 打开之前保存的 .wav 音频文件。
2. p = PyAudio() 和 MediaManager.init() : 与录音时一样，再次初始化音频核心接口和底层媒体硬件，为播
放做准备。
3. stream = p.open(...) : 打开一个音频输出流。从 .wav 文件的动态读取
4. data = wf.read_frames(CHUNK) : 预加载第一块数据。在进入循环前，先从文件中读取一小块音频数据到 
data 变量中，为播放循环做好启动准备。
5. while data : 循环 -> stream.write(data) :命令将 data 变量中的音频数据块“推送”到硬件的播放缓冲区，由
从扬声器发出声音。
