1.4 CanMV IDE界面介绍
 
本节对CanMV IDE的界面进行简单说明，关于CanMV IDE的安装可前往“1.3开发环境搭建”。
1. CanMV IDE界面（为连接K230开发板时）如下：
(1) 菜单栏：操作文件、K230 烧录工具、视觉相关工具等；
(2) 快捷按钮：方便用户开发的部分常用功能快捷方式；
(3) 用户代码编辑区：用户开发 MicroPython 程序的区域；
(4) 设备连接：上方按钮为连接 K230 开发板设备按钮，下方为程序运行、终止按钮；
(5) 调试信息区：显示串口打印的调试信息和搜索功能；
(6) 图像参数区：上方是图像预览区域，下方是色彩空间参数；


===== PAGE 21/33 =====

(7) 固件信息：显示连接的串口号与固件的其他信息。
2. 连接上K230开发板时，左下角的设备连接区变为绿色状态，代表已连接。
3. 运行程序时，左下角的设备连接区变成以上状态。按下
可以停止在线运行。

2. 双击打开CanMV IDE K230；
3. 点击左下角的连接按钮；

1.6.2 终端操作
 
1. CanMV K230 的MicroPython固件集成了交互解释器REPL 【读取(Read)-运算(Eval)-输出(Print)-循环(Loop) 】，
开发者可以直接通过串口终端来调试CanMV K230开发板。我们使用的软件是一款免费的串口终端软件putty。
2. 将开发板连接到电脑，从我的电脑—属性—设备管理器中找到当前的串口号，这里是COM30号。
3. 打开 "2.软件工具\2.3 串口终端工具\Putty.exe”


===== PAGE 28/33 =====

4. 在Connection type选项栏中选择 Serial （Serial 表示串口模式）；根据步骤2查询的端口号填写在Senal line中
（这里以COM30为例）。将Speed中的波特率修改为115200。
5. 在Save Session下方输入1或者自己喜欢的名称，点右边Save，在空白框里面就出现1字样，以后可以直接双击使
用。


===== PAGE 29/33 =====

6. 设置完成后，点击 Open 打开。按下回车键后，若出现 >>>，则表示系统等待输入命令。如果按回车没有出现 
>>>，说明开发板可能正在运行死循环代码，阻塞了 REPL。
7. 在这种情况下，只需按下键盘上的 Ctrl + C 即可。
8. 此时对话框已连接到开发板，CanMV K230 集成了 MicroPython 解析器。在这里我们可以进行调试和编程。接
下来，输入以下代码并按回车查看运行结果。

1.7 显示模式的切换
 
Note
K230支持三种不同的显示模式，分别是 (1: HDMI, 2: LCD, 3: IDE虚拟显示)。用户可以通过修改
select_display 来切换对应的显示模式
1.7.1 HDMI显示模式
 
1. 我们首先将屏幕与K230通过HDMI线缆连接在一起。
2. 修改程序中的select_display 参数，将其修改为1。
# ==================================================================
# == Select the display mode here (1: HDMI, 2: LCD, 3: IDE buffer)(请在这里选择显示模式 (1: 
HDMI, 2: LCD, 3: IDE 缓冲区))
# ==================================================================


===== PAGE 31/33 =====

Note
注意程序中HDMI显示分辨率默认为1920*1080,请修改为您使用中屏幕的对应分辨率，否则K230可能会由于适配
问题出现跑死情况。
1.7.2 LCD显示模式
 
1. 我们首先判断自己的K230是否带3.5寸LCD屏幕，如果没有可以跳过。
# ==================================================================
# == Select the display mode here (1: HDMI, 2: LCD, 3: IDE buffer)(请在这里选择显示模式 (1: 
HDMI, 2: LCD, 3: IDE 缓冲区)) ==
# ==================================================================
select_display = 1 # HDMI显示模式
if display_mode == "hdmi":
     display_size = [1920,1080] #默认为1920*1080,请修改为您使用中屏幕的对应分辨率。
 elif display_mode == "lcd":
     display_size = [800,480]
 else:
     display_size = [1280,720]


===== PAGE 32/33 =====

2. 修改程序中的select_display 参数，将其修改为2。
Note
使用默认分辨率即可，不需要改动。
# ==================================================================
# == Select the display mode here (1: HDMI, 2: LCD, 3: IDE buffer)(请在这里选择显示模式 (1: 
HDMI, 2: LCD, 3: IDE 缓冲区)) ==
# ==================================================================
select_display = 2 # LCD显示模式
if display_mode == "hdmi":
  display_size = [1920,1080] 
elif display_mode == "lcd":
  display_size = [800,480] #默认为800*480,LCD屏幕默认分辨率。
else:
  display_size = [1280,720]


===== PAGE 33/33 =====

1.7.3 IDE虚拟显示模式
 
1. 我们首先将K230与电脑连接起来
2. 修改程序中的select_display 参数，将其修改为3。
Note
使用默认分辨率即可，不需要改动。
# ==================================================================
# == Select the display mode here (1: HDMI, 2: LCD, 3: IDE buffer)(请在这里选择显示模式 (1: 
HDMI, 2: LCD, 3: IDE 缓冲区)) ==
# ==================================================================
select_display = 3 # IDE虚拟显示模式
if display_mode == "hdmi":
display_size = [1920,1080] 
elif display_mode == "lcd":
display_size = [800,480] 
else:
display_size = [1280,720] #默认为1280*720
